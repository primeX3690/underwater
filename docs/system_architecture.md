# System Architecture - Underwater Defense Shield (SwarmOS)

## Overview
The Underwater Defense Shield is a decentralized, AI-driven, acoustic-meshed autonomous UUV (Unmanned Underwater Vehicle) network designed to provide persistent surveillance across the Indian Ocean Region (IOR).

## Key Components
1. **Firmware (Rust):** Low-power duty cycling, self-healing mesh routing, AES-256 encryption.
2. **Propulsion:** Magnetohydrodynamic (MHD) silent thrusters with zero mechanical cavitation.
3. **Edge AI:** On-device ONNX runtime classifying threat signatures from background marine noise.
4. **Surface Gateway:** Real-time satellite uplink via GSAT-7A (Rukmini) to naval command centers.
